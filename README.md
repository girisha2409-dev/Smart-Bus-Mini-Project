##### 

##### \# SMART BUS MONITORING SYSTEM

##### 

##### \## 1. Project Description

##### 

###### The Smart Bus Monitoring System is a web-based application

###### designed to monitor passenger occupancy inside a bus.

###### 

###### It displays the total bus capacity, current passengers,

###### available seats and occupancy percentage.

##### 

##### \## 2. Problem Statement

###### 

###### Passengers often face difficulty knowing how crowded a bus

###### is before boarding. This project provides a dashboard to

###### monitor passenger occupancy and available seats.

##### 

##### \## 3. Objectives

##### 

###### \- Monitor passenger occupancy.

###### \- Display available seats.

###### \- Calculate occupancy percentage.

###### \- Identify bus occupancy status.

###### \- Simulate passenger entry and exit.

##### 

##### \## 4. Features Implemented

##### 

###### 1\. Passenger Entry

###### 2\. Passenger Exit

###### 3\. Available Seat Calculation

###### 4\. Occupancy Percentage

###### 5\. Occupancy Progress Bar

###### 6\. Bus Full Alert

###### 7\. Reset Function

###### 8\. Bus Stop Information

###### 9\. Occupancy Status Monitoring

##### \## 8. Installation Steps

##### 

###### 1\. Download or clone the project repository.

###### 2\. Extract the project folder if downloaded as ZIP.

###### 3\. Open the Smart-Bus-Mini-Project folder.

###### 4\. Open index.html in a web browser.

##### 

##### \## 9. How to Run the Application

##### 

###### 1\. Open the project folder.

###### 2\. Double-click index.html.

###### 3\. The Smart Bus dashboard will open.

###### 4\. Click Passenger Entry to increase the count.

###### 5\. Click Passenger Exit to decrease the count.

###### 6\. Click Reset to clear the passenger count.
